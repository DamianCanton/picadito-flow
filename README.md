# Fútbol 11 Manager ⚽

Aplicación web para organizar partidos de fútbol 11 vs 11, diseñada con estética profesional y pensada para resolver la logística de los grupos grandes.

## Características

- **Gestión de Jugadores**: Pega tu lista del vestuario o agrega jugadores manualmente.
- **Roles y Posiciones**: Define si es ARQ, DEF, MED, DEL o POLI (Polifuncional).
- **Match Maker**: Algoritmo que prioriza formar partidos completos de 22 jugadores.
- **Reservas**: Los jugadores que sobran se gestionan automáticamente en una lista de espera.
- **WhatsApp Ready**: Copia las formaciones listas para enviar al grupo con un solo clic.

## Tecnologías

- React + Vite
- Tailwind CSS
- Zustand (Estado Global)
- Lucide React (Iconos)

## Cómo correrlo localmente

1. Clonar el repositorio.
2. Instalar dependencias:
   ```bash
   npm install
   ```
3. Correr el servidor de desarrollo:
   ```bash
   npm run dev
   ```
